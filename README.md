## О проекте

**MoltenGram** — это мощная и кастомизируемая модификация Telegram для Android, основанная на [exteraless](https://github.com/exteraless/exteraless) (наследнике [exteraGram](https://github.com/exteraSquad/exteraGram) и [NagramX](https://github.com/risin42/NagramX)).

Проект сочетает эстетику чистого **Material 3 / Material You**, плавные интерфейсные решения и продвинутый функционал для медиа, музыки и плагинов.

* **Имя пакета:** `com.moltengram.app` (устанавливается параллельно с официальным Telegram и exteraless).

## Схема наименования релизов

В проекте принята строгая концепция именования каналов обновлений:
* **Release (Стабильные):** Десерты (текущий релиз — **Tiramisu**, прошлые: **Éclair** (v12.10.3), **Soufflé** (v12.10.4), **Macaron** (v12.10.5)). Минорные фиксы не меняют название десерта, а функциональные обновления MoltenGram переходят к следующему десерту независимо от версии Telegram.
* **Beta (Бета):** Ингредиенты и специи релизного десерта (для Tiramisu: *Mascarpone*, *Espresso*, *Cocoa*, *Savoiardi*, *Marsala*).

## Ключевые особенности

### 🎨 Material 3 и интерфейс
- **Карусель медиа (Media Carousel):** отображение альбомов с фото и видео в виде плавной горизонтальной карусели карточек вместо жесткой сетки.
- **Формы аватарок Material 3:** 15 параметрических геометрических форм аватаров (Squircle, Rounded, Cookie, Clover, Hexagon и др.) с индивидуальной настройкой для профилей, групп, каналов и избранного.
- **Кастомизируемый MD3 Speed-Dial FAB:** раскрывающаяся плавающая кнопка с морфингом формы при скролле, расширенной пастельной палитрой тональных цветов и настраиваемым меню быстрых действий.
- **Папки-чипсы:** настраиваемая панель папок чатов со стилями (Filled, Outlined, Ghost), плавным морфингом скруглений и анимациями перехода.
- **Анимации ввода:** плавный курсор, эффекты появления текста и частицы при удалении символов.
- **Коллекция иконок:** фирменные стили оформления лаунчера с адаптивными монохромными слоями под Nothing OS и Google Pixel.

### 🌀 3D-эффекты и визуальный стиль
- **3D-цилиндрический скролл чата:** объемный цилиндрический наклон сообщений при прокрутке списка на базе шейдера AGSL RuntimeShader с точной регулировкой угла кривизны.
- **Матовое стекло сообщений:** настоящие размытые пузыри сообщений в реальном времени с настраиваемой прозрачностью, преломлением и динамическим контурным бликом.

### 🎵 Медиа и плеер
- **Material 3 Video Seekbar:** удобный ползунок перемотки видео в чатах с превью.
- **Продвинутый аудиоплеер:** мини-плеер и верхняя панель в чате с плавной анимацией морфинга формы.
- **Локальные плейлисты:** создание и управление пользовательскими списками воспроизведения музыки с поддержкой экспорта в M3U8 и .mplaylist.
- **Синхронизированные тексты песен:** отображение караоке-текстов треков с поддержкой нескольких провайдеров и настройкой приоритета.
- **Управление воспроизведением:** слайдер скорости с корректировкой высоты тона и непрерывный фоновый звук.

### ⚡ Система, безопасность и интеграции
- **Nothing Glyph Interface:** аппаратное управление светодиодными лентами и глиф-матрицей на смартфонах Nothing Phone (1, 2, 2a, 3, 4) и CMF Phone при вызовах, сообщениях и съемке видеосообщений.
- **Шрифт NDot:** системная поддержка фирменных шрифтов Nothing NDot 55 и NDot 57.
- **Встроенный Tor Proxy:** встроенный нативный клиент Tor (v0.4.9.14) с вращающейся 9-лепестковой кнопкой-печеньем для быстрого защищенного подключения в один тап.
- **Спуфинг устройств:** клиентская маскировка под смартфоны Google Pixel и Nothing Phone.
- **Кастомный эмодзи-статус без Premium:** установка анимированных статусов без подписки Telegram Premium через невидимый био-код.
- **Движок Python-плагинов:** встроенная среда Chaquopy Python 3.12, каталог дополнений с установкой в 1 клик, импорт `.py` скриптов, бэкап и экспорт.
- **Интеграция с Shizuku:** бесшовное фоновое обновление клиента без диалогов системного инсталлятора.
- **Быстрый прокси:** автоматический тест задержки и подключение к самому быстрому серверу.

### Сборка

1. Клонировать репозиторий с подмодулями:

   ```bash
   git clone --recursive --shallow-submodules git@github.com:MoltenSt4r/MoltenGram.git
   cd MoltenGram
   ```

2. Получить `TELEGRAM_APP_ID` и `TELEGRAM_APP_HASH` на [my.telegram.org](https://my.telegram.org/auth) и создать `local.properties` в корне проекта:

   ```properties
   TELEGRAM_APP_ID=<ваш_app_id>
   TELEGRAM_APP_HASH=<ваш_app_hash>
   ```

3. Для подписи APK положить свой `TMessagesProj/release.keystore` и указать параметры в `local.properties`:

   ```properties
   KEYSTORE_PASS=<пароль_хранилища>
   ALIAS_NAME=<имя_ключа>
   ALIAS_PASS=<пароль_ключа>
   ```

   *(Без собственного ключа сборка подпишется стандартным отладочным debug-ключом Android).*

4. Для push-уведомлений положить `TMessagesProj/google-services.json` (пакет `com.moltengram.app`).

5. Собрать через Gradle:

   ```bash
   ./gradlew :TMessagesProj:assembleDebug
   ```

> **Примечание по архитектурам (ABI):** Chaquopy собирает Python 3.12 только под 64-битные `arm64-v8a` и `x86_64`. Переменная окружения `NATIVE_TARGET` задает целевой ABI: `arm64-v8a` (быстрая сборка под телефон), `universal` (оба) или `SKIP` (без нативной части).

### Release Naming Scheme

The project follows a structured naming convention:
* **Release (Stable):** Desserts (current release: **Tiramisu**, previous: **Éclair** (v12.10.3), **Soufflé** (v12.10.4), **Macaron** (v12.10.5)). Minor patch updates retain the dessert codename; significant feature updates advance to the next dessert regardless of Telegram upstream version changes.
* **Beta:** Ingredients or spices associated with the release dessert (for Tiramisu: *Mascarpone*, *Espresso*, *Cocoa*, *Savoiardi*, *Marsala*).
* **Canary:** Chemical elements and compounds (*Titanium*, *Xenon*, *Cobalt*, *Neon*, *Graphene*, *Helium*, *Argon*).
