## 🚀 О проекте

> [!NOTE]
> **MoltenGram** — это мощная и ультракастомизируемая модификация Telegram для Android, построенная на базе [exteraless](https://github.com/exteraless/exteraless) (наследнике [exteraGram](https://github.com/exteraSquad/exteraGram) и [NagramX](https://github.com/risin42/NagramX)).

Клиент объединяет эстетику экспрессивного дизайна **Material 3 / Material You**, плавные физические анимации, аппаратную интеграцию Nothing Glyph, встроенный Tor-демон, караоке-тексты песен и полноценную платформу дополнений на Python 3.12.

## 🛠️ Сборка проекта

Для сборки MoltenGram из исходного кода потребуется установленный **Android Studio / Android SDK** и **JDK 17**:

```bash
# Клонирование репозитория со всеми подмодулями
git clone --recursive --shallow-submodules https://github.com/MoltenSt4r/MoltenGram.git
cd MoltenGram

# Сборка отладочного APK с помощью Gradle
./gradlew :TMessagesProj:assembleDebug
```

> [!TIP]
> Собранный APK файл будет находиться в директории:
> `TMessagesProj/build/outputs/apk/debug/`

### 🚀 About MoltenGram

> [!NOTE]
> **MoltenGram** is a feature-rich, highly customizable Telegram client for Android based on [exteraless](https://github.com/exteraless/exteraless) (the successor to [exteraGram](https://github.com/exteraSquad/exteraGram) and [NagramX](https://github.com/risin42/NagramX)).

It pairs a refined **Material 3 Expressive** aesthetic with the warm coral/terracotta Monet palette (`#FE8A73` / `#7E1D0A`), interactive media carousels, Nothing Glyph LED matrix integration, an on-device Tor daemon, synced lyrics, and an extensible Chaquopy Python 3.12 plugin store.

### 🛠️ Building from Source

To compile MoltenGram from source code, ensure you have **Android Studio / Android SDK** and **JDK 17** configured:

```bash
# Clone the repository recursively with submodules
git clone --recursive --shallow-submodules https://github.com/MoltenSt4r/MoltenGram.git
cd MoltenGram

# Build the debug APK via Gradle wrapper
./gradlew :TMessagesProj:assembleDebug
```
